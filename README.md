# 🐸 Hop's Math Pond

### Making Math Fun, One Hop at a Time!

**Hop's Math Pond** is a free, interactive educational math game designed to help young elementary school children develop foundational math skills through fun, colorful, and engaging activities.

Players join Hop, a friendly frog, on a mathematical adventure across the pond. By answering questions correctly, children help Hop progress, earn stars, and build confidence in their math abilities.

The goal is simple: **Make learning math feel like playing a game!**

## 🎮 Game Features

- 🐸 **Interactive Gameplay:** Help Hop the frog complete math challenges.
- 🔢 **9 Math Activities:** Practice counting, addition, subtraction, and more.
- ⭐ **Earn Stars:** Receive rewards for answering questions correctly.
- 📈 **Adaptive Difficulty:** Five difficulty levels adjust based on performance.
- 🔊 **Audio Assistance:** Questions can be read aloud, with teacher-style and kid-style voice options.
- 🎉 **Positive Reinforcement:** Fun animations, sounds, and encouraging messages.
- 📱 **Mobile-Friendly:** Designed to work on phones, tablets, and computers.
- 🌙 **Light and Dark Modes:** Supports different viewing preferences.
- 💾 **Saved Progress:** Stars and difficulty progress are saved locally in the browser.

## 🚀 How to Play

1. Open Hop's Math Pond in a web browser.
2. Choose one of the nine math activities.
3. Listen to or read each question.
4. Select the correct answer.
5. Earn stars and help Hop jump across the pond!
6. Complete 10 questions to finish a round.
7. Play again to continue practicing and improving.

## 🎯 Educational Goals

Hop's Math Pond is designed to help children:

- Develop foundational mathematics skills.
- Strengthen number recognition and counting.
- Improve addition and subtraction fluency.
- Understand number patterns and place value.
- Build independent problem-solving abilities.
- Gain confidence through repetition and encouragement.

The game is particularly suited for early elementary learners, with adjustable difficulty levels for developing skills.

## 🛠️ Built With

- **HTML5** – Game structure
- **CSS3** – Responsive design, animations, and styling
- **JavaScript** – Game logic, math questions, scoring, and progression
- **Web Speech API** – Spoken instructions and questions
- **Web Audio API** – Interactive sound effects
- **Local Storage** – Saves stars, progress, and voice preferences

No installation, external JavaScript libraries, or backend server is required.

## 💻 Running the Game

To play locally:

1. Download the `index.html` file from this repository.
2. Open it in a modern web browser.
3. Start playing!

The game can also be hosted using **GitHub Pages** for free browser-based access.

Math can sometimes feel intimidating or frustrating for young learners. Hop's Math Pond was created with the belief that children learn best when they are curious, motivated, and having fun.

By combining simple gameplay, colorful visuals, positive encouragement, and interactive math challenges, this project aims to make foundational math practice an enjoyable daily experience.
