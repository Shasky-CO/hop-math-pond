🐸 Hop's Math Pond
Making Math and Reading Fun, One Hop at a Time!
Hop's Math Pond is a free, interactive educational game that helps children build confidence in math, reading comprehension, grammar, and storytelling through playful, age-appropriate challenges.

Children join Hop, a friendly frog, on an adventure through the pond. Every correct answer helps them earn stars, develop new skills, and keep learning. What began as a math game has grown into a broader learning experience for children in kindergarten through fifth grade.

The goal is simple: make learning feel like playing!
🎮 Game Features
- 🐸 22 Learning Activities: Explore 19 math activities and 3 reading and language arts activities.
- 🎓 Grade-Based Learning: Choose kindergarten through fifth grade to see activities suited to that grade.
- 📈 Adaptive Difficulty: Five challenge levels adjust as children answer questions correctly or need more practice.
- 📚 Reading and Language Arts: Build comprehension, strengthen grammar, and explore story structure.
- 🔊 Read-Aloud Support: Listen to supported questions and instructions, with teacher-style and kid-style speech settings, available device voices, and adjustable speaking speed.
- ✏️ Interactive Scratch Paper: Draw, write, or work out answers directly on the screen.
- 💡 Helpful Explanations: Incorrect answers lead to a simple explanation and, when applicable, visual examples.
- ⭐ Stars and Encouragement: Earn rewards, watch Hop celebrate, and receive positive feedback.
- 📋 Grown-Up Progress Report: Review correct and incorrect answers, accuracy by topic, recent missed questions, and practice tips. Progress check-ins also appear at 25-star milestones.
- 📱 Responsive Design: Play on a computer, tablet, or phone.
- 🌙 Light and Dark Appearance: Supports device color-scheme preferences.
- 💾 Browser-Based Progress: Saves stars, grade, difficulty, and selected preferences locally in the browser.

📚 Reading and Language Arts Activities
The pond now includes three dedicated literacy activities, available across kindergarten through fifth grade:
Activity	Learning Objective
📚 Reading	Read stories and informational passages, then answer questions about details, sequence, main ideas, vocabulary, predictions, and inferences
✍️ Sentence Structure	Practice capitalization, punctuation, word order, parts of speech, verb tense, and other grammar skills
🧩 Story Builder	Put story events in order, recognize beginnings and endings, identify problems and solutions, and choose fitting endings or themes


Reading challenges become more complex as grade and difficulty increase. Younger learners encounter simpler passages and questions; older learners practice deeper understanding, including using clues and evidence from a text. Story Builder uses guided, choice-based activities rather than free-form story writing.
🚀 How to Play
1. Open Hop's Math Pond in a modern web browser.
2. Select a grade from kindergarten through fifth grade.
3. Choose a math, reading, or language arts activity.
4. Read or listen to the question, and use scratch paper if helpful.
5. Select an answer and receive immediate feedback.
6. Complete 10 questions to finish a round and see your results.
7. Earn stars, play again, or choose another learning activity.
Grown-ups can change the grade at any time and open the Grown-Up Report from the main menu to review practice results and suggested areas for improvement.
🎯 Educational Goals
Hop's Math Pond is designed to help children:
- Build number sense and mathematical fluency.
- Develop problem-solving and logical thinking skills.
- Improve reading comprehension and identify important story details.
- Recognize story sequence, character actions, and main ideas.
- Strengthen sentence construction, grammar, and punctuation.
- Practice independently with helpful feedback and optional audio support.
- Grow more confident through short, encouraging practice sessions.
The activities are intended for skill practice and enrichment, not as a replacement for classroom instruction or formal assessments.
🛠️ Built With
- HTML5 – Game structure and interface
- CSS3 – Responsive layout, styling, animations, and appearance preferences
- JavaScript – Question generation, gameplay, scoring, and adaptive levels
- Web Speech API – Spoken prompts and voice options
- Web Audio API – Interactive sound effects
- Canvas API – On-screen scratch paper
- Local Storage – Browser-based progress and settings
- Google Fonts (Fredoka) – Optional web-loaded display font
The game is built as a single HTML file. It does not require a backend server, user account, or external JavaScript framework. Browser support for speech and available voices may vary by device.
💻 Running the Game
Play locally
1. Download the index.html file from this repository.
2. Open it in a modern browser, such as Chrome, Edge, Safari, or Firefox.
3. Select a grade and start playing!
Host with GitHub Pages
This project can also be published through GitHub Pages so children can play directly from a website without installing anything.
Progress and privacy
Stars, grade selection, challenge levels, and progress information are stored in the current browser using local storage. The game does not require a login or send learning progress to a game backend. Progress does not automatically sync between devices, and clearing site data may erase saved results. An internet connection may be needed to load the optional Google Font.

❤️ Why This Project?
Learning math or reading can sometimes feel frustrating for young children. Hop's Math Pond was created around a simple belief: children learn best when they feel curious, capable, and encouraged.

By bringing together math practice, reading comprehension, language skills, friendly explanations, and playful rewards, the project aims to make everyday learning a positive experience.

Every child deserves the chance to build confidence in math and reading—one hop at a time!
